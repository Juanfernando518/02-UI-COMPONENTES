❌ Ejemplo Malo

El sistema sólo permite realizar acciones mediante menús largos y pasos repetitivos. No existen atajos, ni personalización, ni opciones rápidas para usuarios frecuentes.

Enviar Mensaje

  1. Abrir menú principal
  2. Seleccionar "Herramientas"
  3. Seleccionar "Mensajería"
  4. Seleccionar "Crear mensaje"
  5. Escribir mensaje
  6. Presionar "Enviar"

✅ Ejemplo Bueno

El sistema incluye atajos de teclado para usuarios expertos y botones visibles para novatos. Las dos formas conviven sin bloquearse entre sí.

Enviar Mensaje

✨ Atajo disponible: CTRL + K para enviar rápido
