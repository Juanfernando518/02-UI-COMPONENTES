❌ Ejemplo Malo

Este sistema usa botones distintos para funciones iguales: distintos colores, iconos inconsistentes, textos diferentes y ubicaciones cambiantes. Esto confunde al usuario y dificulta aprender la interfaz.

✅ Ejemplo Bueno

Aquí todos los botones siguen un mismo estándar visual: mismo color para acciones principales, mismos iconos y textos consistentes. El usuario entiende más rápido.
